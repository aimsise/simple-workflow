**Graded draft**: for every ticket and every round, record the path of the draft file whose text that round's evaluator grades: the output path the orchestrator itself named in the spawn prompt of the planner that wrote the draft (the Phase 3 planner for round 1; for a later round, the retry planner spawned in that round, step b of the retry-with-feedback loop; on the degraded branch, the file the role performed inline wrote), never a path taken from a subagent's return text. After a planner returns, the file at that path must exist and its first line that is neither blank nor a `Change rationale:` line or comment must start with `## ` (the **Draft file** instruction of [references/agent-spawn-prompts.md](references/agent-spawn-prompts.md) Phase 3); otherwise that planner spawn failed (Mandatory role invocations), and, outside the degraded branch, the orchestrator never writes, moves or repairs a draft itself. The text inlined into that evaluator's spawn and the prior draft inlined into the next round's retry planner spawn are both read from that file with the file-read tool right before each spawn, never from memory of an earlier phase. The path recorded for a ticket's last round is its **last evaluated draft**: Step DL-2 copies it, and the **Heading check** of [references/destinations.md](references/destinations.md) compares every delivered file with it. After each retry planner returns, the **Section check** of [references/agent-spawn-prompts.md](references/agent-spawn-prompts.md) (Phase 4, retry-with-feedback loop) compares its draft's headings with the previous round's.
