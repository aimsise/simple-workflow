## Error Handling

Every `ERROR:` before Delivery is atomic: nothing reaches the destination (before Delivery the run writes only under `{scratch}`, plus the one-line `.gitignore` append of Argument Parsing), the `local:` counter is unchanged, and the run stops. A failure during Delivery follows Step DL-4. An error line echoes a `brief=`, `findings=`, `destination=local:` or `template=` path exactly as the user typed it (with backslashes read as `/`; Host notes, **`~` paths**), and prints an `api:` URL without its query string.

| Trigger | Output |
|---|---|
| Empty arguments | Print Usage line, stop (before any preflight) |
| Both `brief=` and `findings=` | `ERROR: brief= and findings= are mutually exclusive. Pass exactly one.` |
| Scratch directory cannot be created | `ERROR: create-ticket cannot create the scratch directory .create-ticket-scratch/ in the working directory (<reason>)` |
| `brief=` / `findings=` path with other characters | `ERROR: <token>= path contains characters this skill does not accept` |
| Unknown destination kind (not an `http://` or `https://` URL either) | `ERROR: unknown destination kind in destination=<spec without query> (expected local:, mcp:, api:, browser: or cli:)` (the spec without its query string, at most 80 characters) |
| `auth_env=` / `template=` / `id_path=` without `api:` or `cli:` | `ERROR: auth_env=, template= and id_path= apply only to an api: or cli: destination` |
| `mcp_<name>=` with neither an `mcp:` destination nor a destination URL without a kind (typed or named in prose) | `ERROR: mcp_<name>= applies only to an mcp: destination` |
| Unknown source kind, or a `source=` value outside its pattern | `ERROR: unknown source kind in source=<spec without query> (expected file:, dir:, mcp:, api:, browser: or cli:)` / `ERROR: source=<spec without query> contains characters this skill does not accept` |
| `source_auth_env=` without an `api:` source | `ERROR: source_auth_env= applies only to an api: source` |
| A typed `api:` source whose URL is plain `http://` to a host that is not a loopback host, with a token variable | `ERROR: source api: a token is not sent over plain http; use https` (a source derived from a platform item URL prints a `Tried:` line with that outcome instead and tries the next channel) |
| A destination URL typed without a kind or named in prose, with `mcp_<name>=`, delivered through a channel other than MCP | Not an error: print `WARNING: mcp_<name>= ignored (the destination is reached via <channel>)` and repeat it in the Final summary |
| `content_type=` / `auth_scheme=` without an `api:` destination, or an `auth_scheme=` value other than `bearer` / `basic` | `ERROR: content_type= applies only to an api: destination` / `ERROR: auth_scheme= applies only to an api: destination` / `ERROR: auth_scheme= must be bearer or basic` |
| `source_content_path=` without an `api:` or `cli:` source, `source_auth_scheme=` without an `api:` source, or a `source_auth_scheme=` value other than `bearer` / `basic` | `ERROR: source_content_path= applies only to an api: or cli: source` / `ERROR: source_auth_scheme= applies only to an api: source` / `ERROR: source_auth_scheme= must be bearer or basic` |
| A typed `browser:` source or destination on a host with no browser tool | `ERROR: this host offers no browser tool; pass source=api:<url> or source=cli:<command>` / `ERROR: this host offers no browser tool; pass destination=api:<url> or destination=cli:<command>` |
| A `cli:` command that carries a literal token value | `ERROR: source cli: a credential in the command line; use $VAR` / `ERROR: destination cli: a credential in the command line; use $VAR` |
| `parent=` with a `local:` destination, or outside its pattern | `ERROR: parent= applies only to an mcp:, api:, browser: or cli: destination` / `ERROR: parent= contains characters this skill does not accept` |
| `parent=` and the destination cannot link items (no or several parent-link parameters; `api:` template or `cli:` command template without `{parent}`) | The `ERROR:` line of that kind in [references/destinations.md](references/destinations.md), at preflight |
| A prose output statement resolves two ways, an input statement four or more ways, or any statement to nothing, and no ask-user tool answers | `ERROR: cannot resolve the request's input or output statement: <statement>` |
| A URL named in prose or typed without a kind needs a sign-in (none at hand, or an HTTP 401 or 403, a sign-in page or a client that is not signed in), and no ask-user tool answers | `ERROR: input <item URL without query> needs a sign-in to <host>: sign in with the platform's command-line client or the browser, or re-run with <re-run tokens, with source_auth_env=<VAR> or auth_env=<VAR> to fill in>` / `ERROR: output <item URL without query> needs a sign-in to <host>: sign in with the platform's command-line client or the browser, or re-run with <re-run tokens, with source_auth_env=<VAR> or auth_env=<VAR> to fill in>` (the Argument Parsing line, spelled per direction) |
| Every channel tried for an input URL named in prose or typed without a kind failed (each attempt printed on a `Tried:` line) | `ERROR: could not read <item URL without query> (tried: <channel>: <outcome>; ...); sign in to <host> with the platform's command-line client or the browser, or re-run with <re-run tokens>` |
| The read probe of every channel tried for an output URL named in prose or typed without a kind failed (each printed on a `Tried:` line) | `ERROR: output <item URL without query>: the derived <channel> could not reach the parent item (<outcome>); nothing created; pass <re-run tokens>` |
| `?sheet=` on a non-workbook source, or an unknown option key | `ERROR: source=file:<path>: unknown option <key> (only sheet= on an .xlsx file)` |
| A source cannot be read (missing file or directory, a file of no supported kind that is not text (a NUL byte in its first 8,000 bytes), unreadable `.xlsx`, no Python 3, a `.pdf` or image file this host's file-read tool cannot show, unavailable or non-read-only MCP tool, missing MCP parameter, HTTP status outside 200-299, an `api:` body with no content at its `source_content_path=`, an unusable `source_content_path=`, `source_content_path=` without `jq` on PATH, a typed `api:` source that returned a sign-in page, a `cli:` client not on PATH, a `cli:` command that failed or printed nothing, a `browser:` page that could not be read or was empty) | The `ERROR:` line of that kind in [references/sources.md](references/sources.md) (e.g. `ERROR: source api:<url without query string> returned a sign-in page, not the content; re-run with source_auth_env=<VAR>, or pass the URL without the api: kind so a signed-in client or browser can be tried`, `ERROR: source cli: <first word> is not on PATH`, `ERROR: source cli:<command> failed (exit <n>: <first line of the error output, at most 200 characters>)`, `ERROR: source cli:<command> returned no content`, `ERROR: source cli:<command> has no content at <path>`, `ERROR: source browser:<url without query string> could not be read (<first line of the error, at most 200 characters>)`, `ERROR: source browser:<url without query string> returned no content`), before Phase 1; nothing delivered |
| More than 50 resolved source specs in the request (counted before any `dir:` expansion or follow-up read) | `ERROR: more than 50 sources; narrow the inputs` |
| A source was truncated (at 60,000 characters, or to its share of the 150,000-character intake total), a `dir:` skipped files (unsupported kind or name, or beyond the 50-source cap), a `dir:` has directories below 5 levels, a follow-up read failed or follow-up reads stopped at the 50-source cap, or a workbook got no sheet render | Not an error: continue, print the `WARNING:` line of [references/sources.md](references/sources.md), repeat it in the Final summary |
| Unknown `depth=` or `confirm=` value | `ERROR: depth= must be standard, thorough or exhaustive` / `ERROR: confirm= must be yes or no` |
| No ask-user tool on this host and no `confirm=` token | Not an error: `confirm=yes` is implied; print `NOTE: this host has no ask-user tool; running as if confirm=yes was passed (a remote create is not confirmed first, and a ticket still graded FAIL is delivered as FAIL (unresolved)); pass confirm=no to stop instead` once right after the destination preflight, repeat it in the Final summary, continue |
| Unknown `render=` value | `ERROR: render= must be auto, off, excel or soffice` |
| A `rounds=` value other than an integer from 1 to 5, or a `max_tickets=` value other than an integer from 1 to 30 | `ERROR: rounds= must be an integer from 1 to 5` / `ERROR: max_tickets= must be an integer from 1 to 30` |
| Unknown `constraint_<key>=` key, or a value other than `off` | `ERROR: unknown constraint key <key>` / `ERROR: constraint_<key>= accepts only off` |
| Destination preflight fails | The `ERROR:` line of the failing check in [references/destinations.md](references/destinations.md) (e.g. `ERROR: destination local: <dir> is not a usable directory path (no .. segment, .git, leading -, quote, backtick, dollar or control character)`, `ERROR: template= <path> is not a usable file path (no .. segment, .git, leading -, quote, backtick, dollar or control character)`, `ERROR: destination mcp:<server> exposes no tool that accepts a title and a body`, `ERROR: destination api: unusable content_type <value>`, `ERROR: destination cli: unusable command template (<rule>)`, `ERROR: destination cli: <first word> is not on PATH`, `ERROR: destination cli: the probe <probe command> failed (exit <n>); nothing created`, `ERROR: destination cli: the command template names none of {title_file}, {body_file} or {request_file}`, `ERROR: destination cli: {request_file} needs jq 1.6 or later on PATH`, `ERROR: destination cli: parent= needs a {parent} placeholder in the command template or its template=`, `ERROR: destination cli: the command template uses {parent} but no parent= was given`, `ERROR: destination cli: environment variable <VAR> is not set`, or `ERROR: destination browser:<url without query string>: no create form with a title and a body field (<outcome>)`), before Phase 1 |
| A findings `slug_hint` or a brief `slug` that is not kebab-case | Not an error: it is normalized by the kebab rule of Step D-1 (with its `work-{yyyymmddthhmmssz}` fallback); print `WARNING: <field> "<value>" is not kebab-case; using <normalized>` and repeat it in the Final summary (the `Brief Slug` row keeps the brief's original value) |
| `local:` counter non-numeric | `ERROR: {dir}/.ticket-counter contains non-numeric value '<content>'. Fix or delete the file and retry.` |
| `findings=<path>` not found by the file-read tool | `ERROR: Findings file not found at <path>` |
| Brief file not found by the file-read tool | `ERROR: Brief file not found at <path>` |
| Brief frontmatter without `slug` | `ERROR: brief frontmatter is missing slug` |
| Findings frontmatter without `title` | `ERROR: findings frontmatter is missing title` |
| `findings_version` missing or != 1 | `ERROR: findings_version missing or unsupported (expected 1)` |
| Findings zero `## Required Work Units` | `ERROR: findings file contains zero Required Work Units` |
| A mandatory role's subagent spawn errors, returns nothing, returns a shape that cannot be parsed as its envelope, or (planner) returns `Status: partial` | Not yet an error: print `WARNING: <role> spawn failed (<reason>); retrying once` and run that spawn again once with the same prompt; when the retry fails too, report the error and stop; nothing is delivered (for the decomposer: `ERROR: decomposer agent unavailable`). Never a retry for a remote create or for an explicit `Status: failed` or `Status: ERROR` envelope (next rows) |
| Researcher `Status: partial` | Not an error: continue, print `WARNING: researcher returned partial findings: <limitations>`, repeat it in the Final summary |
| Researcher `Status: failed` | Report the error and stop; nothing is delivered |
| Decomposer `Status: partial` | Not an error: continue with the returned tickets, write the dropped units to `{scratch}/overflow-findings.md` (Step D-4), print `WARNING: decomposer dropped <n> work units beyond the <N>-ticket cap: <titles>; re-run with findings=<{scratch} path>/overflow-findings.md to create them` and repeat it in the Final summary |
| Decomposer `Status: failed`, or an empty Tickets list | `ERROR: decomposer failed — <Rationale>`, or `ERROR: decomposer returned zero tickets`; a `Status: failed` whose Rationale reports a dependency cycle prints the `circular` line of the next row instead |
| Cyclic `depends_on` (reported by the decomposer, or found by Step F-6 / DL-1) | `ERROR: circular dependency detected among tickets: <cycle members>`; literal `circular` MUST appear |
| Planner `Status: failed`, or `Status: partial` again after its one retry | Report the error and stop; nothing is delivered |
| Ticket-evaluator `Status: ERROR` (rubric fail-fast) | Never retried: report the error and stop; nothing is delivered |
| FAIL after max `rounds=` rounds (default 3: initial + 2 revisions) | With `confirm=yes`, typed or implied (no ask-user tool, no `confirm=` token): no question; print the issues, the ticket's verdict is `FAIL (unresolved)`, continue to Delivery. Without it: present the issues with the ask-user tool, in ONE question for every ticket still graded FAIL after its last round (one answer covers them all). Proceed → the ticket's verdict is `FAIL (user-accepted)`; decline → `ERROR: unresolved FAIL gates; the user declined to proceed (draft saved under {scratch})`, stop. A denied or erroring ask-user tool, or no ask-user tool with `confirm=no` → `ERROR: cannot resolve FAIL gates non-interactively; re-run interactively, or with confirm=yes to deliver as FAIL (unresolved) (draft saved under {scratch})`, stop. Do NOT hang. |
| User declines to proceed at the exhausted-retry question | `ERROR: unresolved FAIL gates; the user declined to proceed (draft saved under {scratch})` — nothing delivered |
| Split partial failure | Any sub-ticket without a verdict → nothing delivered (atomic — Delivery starts only after all N have one). A ticket whose exhausted-retry escalation ended in "proceed" (`FAIL (user-accepted)` or `FAIL (unresolved)`) has a verdict and is delivered with the others; the run stops with nothing delivered only when the escalation of at least one ticket ended in a stop |
| A remote destination with `confirm=no` on a host with no ask-user tool (the last step of the destination preflight, before Phase 1), or an ask-user tool that errors or is denied at the confirmation before the first create | `ERROR: remote delivery needs an interactive confirmation; re-run with confirm=yes to skip it` (for a derived destination followed by ` (derived: <the derived tokens>)`) — nothing created |
| The user answers no at the confirmation before the first remote create | `ERROR: remote delivery declined; nothing created` |
| `local:` path already exists | `ERROR: create-ticket write refused — <path> already exists` — nothing written, counter untouched |
| `local:` split-plan validation fails | `ERROR: split-plan validation failed — <reason>` — quarantined like a write failure (`mv` to `{dir}/.rollback/{parent-slug}-{ts}/`, never delete) |
| `local:` write failure | `ERROR: create-ticket write failed — partial output quarantined at {dir}/.rollback/{parent-slug}-{ts}/ (<reason>)` — counter untouched; re-run with the same inputs is safe |
| `local:` counter write fails after the tickets are written | `ERROR: create-ticket counter write failed — set {dir}/.ticket-counter to <counter + N> (<reason>)` — the tickets stay in place; stop |
| `mcp:` / `api:` / `browser:` / `cli:` create failure | The identifiers created so far, then `ERROR: destination <spec> create failed for <logical id> (<reason>)` (for `cli:` the spec is `cli:<first word>`, for `browser:` the URL without its query string) — nothing deleted or modified, no other channel tried, stop |
