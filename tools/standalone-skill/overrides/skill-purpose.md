heading: ## Pre-computed Context
mode: before
---
This skill turns a request, a brief, an investigation record or the user's own material into one or more implementation tickets: a planner role drafts each ticket, an independent evaluator role grades it against a fixed quality rubric, and the graded tickets are delivered to one destination, a local directory by default or a ticket platform. It runs only when the user invokes it by name.
